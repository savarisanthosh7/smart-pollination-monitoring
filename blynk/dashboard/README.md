# Blynk Dashboard

The dashboard is intended to provide remote visibility of the pollination-monitoring node.

## Dashboard layout

```text
+----------------------------------+
| SMART POLLINATION MONITOR        |
+----------------------------------+
| Current State | Confidence       |
|---------------|------------------|
| Bee Activity  |  -- %            |
+----------------------------------+
| Device Status | Last Update      |
+----------------------------------+
| Activity History                 |
|                                  |
+----------------------------------+
| Alert / Communication Status     |
+----------------------------------+
```

Use the actual Blynk template and virtual pins from the deployed project when configuring the live dashboard. This repository does not invent token values or claim a particular dashboard screenshot.

# Hardware Components

| Component | Role |
|---|---|
| ESP32 development board | Main embedded controller |
| INMP441 | Digital MEMS microphone for bee/ambient acoustic sensing |
| SX1278 LoRa module | Long-range wireless communication |
| Antenna | LoRa RF interface |
| Stable power supply | Powers the sensing node |
| Breadboard / PCB and jumper wires | Prototype interconnection |

## Before assembly

Confirm the exact board variant, supply voltage, module frequency, antenna connection, and GPIO mapping used by the physical prototype. The repository intentionally does not invent undocumented wiring.

# Images and Figures

This directory is the project asset location for the visual evidence produced during development and testing.

## Project figures to store here

Use this directory for the actual:

- System architecture diagram
- Physical hardware-node photographs
- INMP441 and ESP32 wiring photographs
- SX1278 transmitter/receiver photographs
- Blynk dashboard screenshots
- AI preprocessing/Mel-spectrogram figures
- CNN training curves
- Confusion matrix figure
- Field deployment photographs
- LoRa reception/range test plots

## Naming convention

```text
01-system-architecture.png
02-hardware-node.jpg
03-lora-receiver.jpg
04-blynk-dashboard.png
05-audio-preprocessing.png
06-training-history.png
07-confusion-matrix.png
08-field-deployment.jpg
```

Only add photographs and measurement figures that actually belong to this project. Do not use stock images as evidence of a prototype or field test.

Large binary assets should be stored using an appropriate release/artifact mechanism when they exceed normal Git repository limits.

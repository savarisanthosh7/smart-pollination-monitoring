# Model Artifacts

This directory is reserved for models generated by the training pipeline.

## Generated artifacts

A training run can produce:

- `beewatch_cnn.keras` — final trained Keras model.
- `best_model.keras` — checkpoint with the best validation loss during training.
- `classes.txt` — class order used by the classifier.
- `training_history.csv` — epoch-level training/validation metrics.
- `classification_report.txt` — validation classification metrics generated by scikit-learn.
- `confusion_matrix.csv` — validation confusion matrix.

## Model provenance

A model file should only be treated as an official project model when its dataset version, preprocessing configuration, training configuration and evaluation results have been recorded.

No trained weights are claimed here until an actual training run produces them. This prevents the repository from presenting an unverified model as an original experimental artifact.

## Releasing a model

Before committing a generated model, check its size and repository policy. For large model files, use an appropriate artifact/model-storage mechanism instead of committing binaries directly to Git.
